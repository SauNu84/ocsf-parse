What it does

One engine, many sources

Declarative JSON DSL with 11 op kinds. The same engine reads nginx access logs, CloudTrail JSON, Sysmon events, and Suricata alerts. Add a new source by writing a config file — no code.

LLM-assisted onboarding

Drop a sample log into the /new wizard. The generator suggests OCSF classes, drafts a full mapping JSON, and the linter gates the save. Anthropic / OpenAI / offline fixture providers — bring your own key.

CI-linted

Every mapping ships with a pinned sample. The linter re-runs every mapping × sample on every PR and refuses to merge if any event no longer conforms to OCSF.

Built for scale

Multiprocess apply --workers N, streaming partitioned Parquet for AWS Security Lake, optional orjson fast-path. ~30-50× over single-thread for 10 TB-class workloads. See benchmarks.

Install

Docker

docker run --rm -p 8000:8000 \
  ghcr.io/saunu84/ocsf-mapper:latest

→ web UI on http://127.0.0.1:8000

PyPI

pip install 'ocsf-mapper[web,parquet,fast]'
ocsf-mapper serve

Optional extras: fast (orjson), parquet (pyarrow), web (FastAPI).

Source

git clone --recurse-submodules \
  https://github.com/SauNu84/ocsf-parse
cd ocsf-parse
pip install -e '.[dev,web,parquet,fast]'

CLI surface

ocsf-mapper apply       mappings/cloudtrail.json samples/cloudtrail.jsonl out.jsonl
ocsf-mapper apply       … --workers 8 --sink security-lake   # 10 TB-class
ocsf-mapper apply       … --redact email ipv4                # PII scrub
ocsf-mapper validate    out.jsonl authentication
ocsf-mapper list                                              # mapping table
ocsf-mapper catalog                                           # master data
ocsf-mapper lint                                              # CI gate
ocsf-mapper schema-diff                                       # break detector
ocsf-mapper benchmark   mappings/X.json samples/X.ext         # throughput
ocsf-mapper diff        a.json b.json                          # mapping diff
ocsf-mapper generate    my_src samples/my.jsonl               # LLM draft
ocsf-mapper tail        mappings/X.json /var/log/X.log         # live -f
ocsf-mapper serve                                              # web UI
